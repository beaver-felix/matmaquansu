# Web-Game: Cơ Yếu Quân Sự Việt Nam (1945–1975)

> **Não cá vàng mở repo? Đọc đúng 3 bước này (mất 30 giây):**
> 1. Mở **[STATUS.md](./STATUS.md)** → biết ngay **đang làm tới đâu**, **vừa xong gì**, **làm gì tiếp theo**.
> 2. Mở **[docs/ROADMAP.md](./docs/ROADMAP.md)** → xem checklist chi tiết từng task (`T0.1` → `T8.2`), file cần đụng và cách verify.
> 3. Mở **[docs/GAME_SPEC.md](./docs/GAME_SPEC.md)** → tra chi tiết cảnh game (Scene 0–8), thông số 5 xe, 4 kĩ năng cơ yếu, dòng thời gian lịch sử.

## Quy tắc nghỉ tay (Bắt buộc trước khi tắt máy)
1. Tick `[x]` các task đã xong trong [docs/ROADMAP.md](./docs/ROADMAP.md).
2. Cập nhật mục **Đang ở đâu** và thêm 1 dòng vào **Nhật ký phiên làm việc** trong [STATUS.md](./STATUS.md).
3. Chạy kiểm tra nhanh (`pnpm typecheck` / `pnpm build`) khi đã khởi tạo project.
